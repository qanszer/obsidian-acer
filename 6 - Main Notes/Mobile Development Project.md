# Mobile Development Project


**Application Title: Provide a suitable and original name for the proposed application.**

None yet. Give ideas

**• Problem Statement: Describe the problem, situation, or need that the application intends to address.**

During lecture, some students have questions but they don't ask it when the professor gives them the time to do so because they are either:
- afraid that they will be thought of as stupid by the others for asking a simple question
- do not want to speak loudly
- prefer the question to be anonymous
- forgot their question by the time the professor gave time for questions

**• Proposed Solution: Explain how the application will address the identified problem or need.**

An app where the students can type out their questions there anonymously, in real time, during the lecture wherein the professor will read and answer it after a segment of their lecture is done or whenever he/she likes.

**• Main Features: List the major functions that the application is expected to provide.**

**Features**
1. Professor
	- can make a classroom (permanent gc) where students can join
	- can view the pending questions list anytime they want to
	- can remove a pending question (ideally after they answered)
	- 
2. Student
	- can join a classroom using a 4-letter code from the professor
	- can add a question for the professor anonymously
	- can remove their own question if it gets answered or they solved it on their own before the professor gives time to ask questions
	- can edit their question anytime
